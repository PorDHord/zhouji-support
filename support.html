开始使用

首次打开可以先体验示例。进入“我的”创建或修改工作分类，按需要连接一个可写的系统日历，然后从“记一笔”录入工作。地点和时间可分别输入，金额可以稍后补。

日历为什么没有同步？

在“我的”确认已开启双向同步、授予完整日历访问权限，并为分类连接可写日历。Mac 上创建的日程需要先到达 iPhone 原生日历，周迹才能读取。打开或返回周迹可触发刷新；应用不保证后台即时同步。生日与订阅日历不能作为可写工作日历。

删除和取消有什么区别？

“已取消”是工作状态，不等于删除系统事件。删除时可以选择仅删除周迹记录，或同时删除关联日历事件。系统日历侧删除会在复核后反映到周迹。整本系统日历不会因删除应用内分类而被删除。

如何快速输入多笔？

将带编号的多条文字粘贴到批量录入，解析后逐条检查地点、备注和日期，确认后保存。它使用本机规则，不保证理解任意自然语言；不确定的时间和金额请自行补充。

金额和结算

首页和结算列表都能直接补改金额，未填和 0 元分别处理。当前公司结算保留“恒居”这一预设，只汇总归属恒居且已完成的工作；个人工作可查看收入统计。应用不是财务或税务系统，导出前请核对结果。业务日期按北京时间处理。

备份与 iCloud

在“我的”导出完整 JSON 备份并妥善保管。当前不提供在应用内导入任意 JSON 备份的通用恢复入口，请不要通过卸载来排查问题。iCloud 账本同步可选、默认关闭；系统日历同步与账本同步是两个独立过程。更换设备前请先导出备份，并核对实际同步结果。

小组件

在 iPhone 桌面编辑模式中添加周迹小组件。“我的”提供生日、节假日的独立开关。更新频率由 iOS 决定；敏感信息尽量放在私人备注，不放标题。
